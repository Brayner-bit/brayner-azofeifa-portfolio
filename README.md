# Portafolio web de Brayner Azofeifa

Sitio estático bilingüe preparado para publicarse con GitHub Pages.

## Vista local

Ejecutar desde esta carpeta:

```powershell
python -m http.server 8080
```

Abrir `http://localhost:8080`.

## Publicación en GitHub Pages

Subir el contenido de esta carpeta a un repositorio y activar **Settings > Pages > Deploy from a branch**, seleccionando la rama principal y la carpeta raíz.
